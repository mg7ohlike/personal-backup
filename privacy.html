Privacy Policy

Personal Backup is a personal tool. Its only user is its owner.

What it accesses

It uses the Google Drive API with the drive.file scope. That scope covers only the files this app creates. The app does not read, list or change any other file in the owner's Google Drive, and it does not access any other Google service or user data.

What it stores

It uploads backup archives that are encrypted on the owner's own computer before upload. Google stores them only as encrypted data.

Sharing

No data is sold, shared with third parties, or used for advertising or analytics.

Revoking access

The owner can revoke the app's access at any time in the Google Account settings, under Security, Third-party apps.
